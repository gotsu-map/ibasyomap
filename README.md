## サイト構造

- トップ（index.html）でフローチャートを表示
- バナー画像（banner.png）が検索欄の上に表示
- 各色のカードをクリック → 対応するHTMLページへ遷移
- 各ページに「← もどる」でトップへ戻る
- 検索欄（場所名・説明・カテゴリ名で横断検索）→ 対応ページへ遷移
- 各ページ下部に「掲載準備中の場所」セクション（点線カード）あり

## よくある編集パターン

### 施設を追加する
「○○（ページ名）に△△という施設を追加してください」と伝える。
URLや写真・営業時間・料金があれば一緒に伝えると反映できます。

### 掲載確認中 → 正式掲載に切り替える
「○○の△△の詳細を追加して。営業時間は××、費用は○○、説明は〜〜」と伝える。

### 施設にURLをリンクする
「○○の△△にこのURL（https://...）を登録して」と伝える。

### デザインを変更する
「○○ページの××の間隔を広げて」など具体的に伝える。

### 新しいカテゴリページを追加する
「○○という新しい場所のカテゴリを追加したい」と伝える。

## 公開方法（Netlify）

1. [drop.netlify.com](https://drop.netlify.com) をシークレットモードで開く
2. **全ファイル**（html×8 + banner.png）を同じフォルダにまとめてドラッグ＆ドロップ
3. URLが自動発行される

※ファイルを更新した場合は再度ドラッグ＆ドロップでOK（同じURLに上書きされます）
